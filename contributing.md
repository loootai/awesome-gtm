# Contributing

Pull requests are welcome. This list is short on purpose, so a tool has to earn its place.

## Rules for an entry

- The repository exists, is not archived and has a push in the last 12 months. Check with `gh api repos/<owner>/<name>`.
- It has working code. Closed products with no code belong only in the Data APIs section, with a link to official docs.
- It does something for GTM engineering: prospecting, enrichment, SEO, research, outreach or the data behind them.
- One line, in the form `- [name](url) - Description.` The description says what it does, ends with a period and has no marketing words.
- Say so in the description when a tool needs a paid account, or uses AGPL or GPL.
- Alphabetical order inside a section, ignoring case.
- Add one entry per pull request, or a few from the same section.
- Do not add your own project unless you disclose that in the pull request.

## Sections

Put an entry in the section that fits best. If none fits, suggest a new section in the pull request.

## Removing an entry

Open a pull request if a repository is archived, deleted or has had no push in 12 months.
